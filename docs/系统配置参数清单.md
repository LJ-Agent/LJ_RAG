## 5. 分块策略 (RAG-PYTHON)

| 参数 | 默认值 | 来源 | 说明 |
|------|--------|------|------|
| `chunk.default_size` | 500 | RAG-PYTHON | 默认分块大小(字符) |
| `chunk.max_chunk_size` | 30000 | RAG-PYTHON | 最大分块大小(字符)，受 Milvus VarChar 65535 限制 |
| `chunk.overlap` | 50 | RAG-PYTHON | 块重叠大小(字符) |
| `chunk.min_chunk_size` | 100 | RAG-PYTHON | 最小有效分块(字符)，少于此值丢弃 |
| `chunk.strategy` | semantic | RAG-PYTHON | 默认分块策略: fixed / hierarchical / semantic / recursive / topic / hybrid |

### 分块策略说明

| 策略 | 说明 | 适用场景 |
|------|------|----------|
| `fixed` | 固定大小分块 + 重叠 | 通用文本 |
| `hierarchical` | 按 Markdown 标题层级分块 | 结构化文档 |
| `semantic` | 按段落 + 语义合并 | 自然语言文档 |
| `recursive` | 递归字符分割 + 分隔符优先级 | 代码/表格文档 |
| `topic` | 主题相似度检测分块 | 多主题长文档 |
| `hybrid` | 两阶段：结构化粗分 + 精细递归 | 复杂混合文档 |

## 附录：配置修改后生效方式

| 服务 | 配置类型 | 生效方式 |
|------|----------|----------|
| RAG-BACKEND | application.yml / .env | 重启 Java 服务 (`docker restart rag-server`) |
| RAG-PYTHON | settings.yaml / .env | 重启 Python 服务 (`docker restart rag-python`) |
| RAG-CLEANING | settings.yaml / .env | 重启清洗服务 (`docker restart rag-cleaning`) |
| RAG-MEMORY | settings.yaml / .env | 重启记忆服务 (`docker restart rag-memory`) |
| RAG-QUE | settings.yaml / .env | 重启 QUE 服务 (`docker restart rag-que`) |
| RAG-Web | .env.development | Vite HMR 自动热更新，或刷新浏览器 |
| Docker Compose | .env | `docker compose up -d` 重建容器 |

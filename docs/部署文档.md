# RAG知识库系统 — 部署文档

## 一、环境要求

| 组件 | 版本要求 | 用途 |
|------|----------|------|
| JDK | 17+ | Java运行时 |
| MySQL | 8.0+ | 业务数据库 |
| Redis | 7.x | 缓存 / 分布式锁 / 限流 |
| Kafka | 3.x | 异步消息队列 |
| MinIO | RELEASE.2024+ | 对象存储（文件） |
| Python | 3.10+ | AI服务端（gRPC） |
| Maven | 3.9+ | 项目构建（仅开发环境） |
| Docker | 24+ | 容器化部署 |
| Docker Compose | 2.x | 多容器编排 |

## 二、基础设施部署

### 2.1 Docker Compose 一键启动（推荐）

创建 `docker-compose.yml`：

```yaml
version: "3.8"
services:
  mysql:
    image: mysql:8.0
    container_name: rag-mysql
    restart: unless-stopped
    environment:
      MYSQL_ROOT_PASSWORD: root123
      MYSQL_DATABASE: rag_db
      MYSQL_CHARSET: utf8mb4
      MYSQL_COLLATION: utf8mb4_unicode_ci
    ports:
      - "3306:3306"
    volumes:
      - mysql_data:/var/lib/mysql
      - ./sql:/docker-entrypoint-initdb.d  # 自动执行SQL

  redis:
    image: redis:7-alpine
    container_name: rag-redis
    restart: unless-stopped
    command: redis-server --requirepass redis123 --appendonly yes
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data

  kafka:
    image: bitnami/kafka:3.6
    container_name: rag-kafka
    restart: unless-stopped
    environment:
      KAFKA_CFG_NODE_ID: 0
      KAFKA_CFG_PROCESS_ROLES: controller,broker
      KAFKA_CFG_CONTROLLER_QUORUM_VOTERS: 0@kafka:9093
      KAFKA_CFG_LISTENERS: PLAINTEXT://:9092,CONTROLLER://:9093
      KAFKA_CFG_ADVERTISED_LISTENERS: PLAINTEXT://localhost:9092
      KAFKA_CFG_LISTENER_SECURITY_PROTOCOL_MAP: CONTROLLER:PLAINTEXT,PLAINTEXT:PLAINTEXT
      KAFKA_CFG_CONTROLLER_LISTENER_NAMES: CONTROLLER
    ports:
      - "9092:9092"
    volumes:
      - kafka_data:/bitnami

  minio:
    image: minio/minio:latest
    container_name: rag-minio
    restart: unless-stopped
    command: server /data --console-address ":9001"
    environment:
      MINIO_ROOT_USER: minioadmin
      MINIO_ROOT_PASSWORD: minioadmin123
    ports:
      - "9000:9000"   # API
      - "9001:9001"   # Web控制台
    volumes:
      - minio_data:/data

volumes:
  mysql_data:
  redis_data:
  kafka_data:
  minio_data:
```

启动所有基础设施：

```bash
docker-compose up -d
```

### 2.2 手动部署各组件

#### MySQL

```bash
docker run -d --name rag-mysql \
  -e MYSQL_ROOT_PASSWORD=root123 \
  -e MYSQL_DATABASE=rag_db \
  -p 3306:3306 \
  mysql:8.0
```

初始化数据库表结构：

```bash
mysql -h127.0.0.1 -uroot -proot123 rag_db < sql/V1__init_schema.sql
mysql -h127.0.0.1 -uroot -proot123 rag_db < sql/V2__init_data.sql
```

#### Redis

```bash
docker run -d --name rag-redis \
  -p 6379:6379 \
  redis:7-alpine redis-server --requirepass redis123
```

#### Kafka

```bash
docker run -d --name rag-kafka \
  -p 9092:9092 \
  -e KAFKA_CFG_NODE_ID=0 \
  -e KAFKA_CFG_PROCESS_ROLES=controller,broker \
  -e KAFKA_CFG_CONTROLLER_QUORUM_VOTERS=0@localhost:9093 \
  -e KAFKA_CFG_LISTENERS=PLAINTEXT://:9092,CONTROLLER://:9093 \
  -e KAFKA_CFG_ADVERTISED_LISTENERS=PLAINTEXT://localhost:9092 \
  -e KAFKA_CFG_LISTENER_SECURITY_PROTOCOL_MAP=CONTROLLER:PLAINTEXT,PLAINTEXT:PLAINTEXT \
  -e KAFKA_CFG_CONTROLLER_LISTENER_NAMES=CONTROLLER \
  bitnami/kafka:3.6
```

#### MinIO

```bash
docker run -d --name rag-minio \
  -p 9000:9000 -p 9001:9001 \
  -e MINIO_ROOT_USER=minioadmin \
  -e MINIO_ROOT_PASSWORD=minioadmin123 \
  minio/minio server /data --console-address ":9001"
```

MinIO启动后，登录控制台（http://localhost:9001），创建bucket `rag-documents`。

## 三、应用部署

### 3.1 编译构建

```bash
cd RAG
mvn clean package -DskipTests
```

构建产物：`target/rag-server-1.0.0-SNAPSHOT.jar`

### 3.2 Docker镜像构建与运行

```bash
# 构建镜像
docker build -t rag-server:latest -f docker/Dockerfile .

# 运行容器
docker run -d --name rag-server \
  --network host \
  -e SPRING_PROFILES_ACTIVE=prod \
  -e MYSQL_HOST=127.0.0.1 \
  -e MYSQL_PORT=3306 \
  -e MYSQL_USERNAME=root \
  -e MYSQL_PASSWORD=root123 \
  -e REDIS_HOST=127.0.0.1 \
  -e REDIS_PORT=6379 \
  -e REDIS_PASSWORD=redis123 \
  -e KAFKA_BOOTSTRAP_SERVERS=127.0.0.1:9092 \
  -e MINIO_ENDPOINT=http://127.0.0.1:9000 \
  -e MINIO_ACCESS_KEY=minioadmin \
  -e MINIO_SECRET_KEY=minioadmin123 \
  -e GRPC_RETRIEVAL_HOST=127.0.0.1 \
  -e GRPC_RETRIEVAL_PORT=50051 \
  -e GRPC_GENERATION_HOST=127.0.0.1 \
  -e GRPC_GENERATION_PORT=50052 \
  -p 8080:8080 \
  rag-server:latest
```

### 3.3 直接运行（开发/测试）

```bash
java -jar target/rag-server-1.0.0-SNAPSHOT.jar --spring.profiles.active=dev
```

或使用Maven：

```bash
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

## 四、环境变量详解

| REDIS_PASSWORD | redis123 | Redis密码 |

| MINIO_ACCESS_KEY | minioadmin | MinIO AccessKey |
| MINIO_SECRET_KEY | minioadmin123 | MinIO SecretKey |
| GRPC_RETRIEVAL_HOST | localhost | 检索服务地址 |
| GRPC_RETRIEVAL_PORT | 50051 | 检索服务端口 |

## 七、启动顺序

1. **基础设施**：MySQL → Redis → Kafka → MinIO（按此顺序）
2. **数据库初始化**：执行SQL脚本
3. **Python AI服务**：检索服务 + 生成服务
4. **Java应用**：最后启动

## 八、生产环境建议

1. **MySQL**：至少主从复制，数据目录挂载SSD
2. **Redis**：哨兵/集群模式，开启AOF持久化
3. **Kafka**：3节点集群，replication factor ≥ 2
4. **MinIO**：分布式模式（4节点起步），纠删码容错
5. **Java应用**：至少2个实例 + Nginx负载均衡
6. **日志**：接入ELK/Loki集中收集
7. **监控**：Prometheus + Grafana，关键指标：QPS、延迟、错误率、JVM堆内存
8. **JVM参数建议**：
   ```
   -Xms1024m -Xmx2048m
   -XX:+UseG1GC
   -XX:MaxGCPauseMillis=200
   -XX:+HeapDumpOnOutOfMemoryError
   -XX:HeapDumpPath=/tmp/heapdump.hprof
   ```

## 九、常用运维命令

```bash
# 查看应用日志
docker logs -f rag-server

# 重启服务（不停机：先启动新实例再接流量）
docker restart rag-server

# 数据库备份
mysqldump -h127.0.0.1 -uroot -proot123 rag_db > rag_db_backup_$(date +%Y%m%d).sql

# Kafka查看消息堆积
kafka-consumer-groups.sh --bootstrap-server localhost:9092 --group rag-group --describe

# 清理Docker未使用资源
docker system prune -a
```
